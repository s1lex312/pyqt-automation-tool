# PyQt Desktop Automation Tool

Десктопное приложение на PyQt6 с асинхронным интерфейсом, защитой HWID и интеграцией с API

## Возможности

- Асинхронный интерфейс
- Интеграция с API
- HWID-защита
- Уведомления
- Выгрузка в Excel
- Мультипрофильность

## Технологии

- Python 3.10+
- PyQt6
- curl-cffi
- asyncio + qasync
- pandas

## Установка

```bash
pip install -r requirements.txt
python main.py
