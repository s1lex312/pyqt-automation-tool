# PyQt Desktop Automation Tool

Десктопное приложение на PyQt6 с асинхронным интерфейсом, защитой HWID и интеграцией с API

## Возможности

- Асинхронный интерфейс
- Интеграция с API
- HWID-защита
- Уведомления
- Выгрузка в Excel
- <img width="621" height="194" alt="excel" src="https://github.com/user-attachments/assets/c713cb77-bf9f-4c7c-969a-ae39260773c6" />
- Мультипрофильность

## Технологии

- Python 3.10+
- PyQt6
- curl-cffi
- asyncio + qasync
- pandas

## Установка

```bash
pip install -r requirements.txt
python main.py
